# Bebop-vision project dependencies — ONE venv for the whole project.
#
# Target: Jetson AGX Thor, JetPack 7.2 / L4T 39.2, CUDA 13.2, Python 3.12.
# The recorder/perception/places stack AND the voice stack (Qwen3-Omni via
# TensorRT Edge-LLM) share `bebop-vision/.venv`.
#
# The venv is created with --system-site-packages so JetPack's TensorRT
# Python bindings (system dist-packages) are visible to the voice stack.
# numpy/scipy/pandas are pinned HERE so their venv-local numpy-2 builds
# SHADOW the system numpy-1-built copies. The venv-local scipy matters:
# without it, transformers' optional `from scipy.optimize import ...`
# resolves to the system scipy and dies on `from numpy import Inf`.
#
# Do NOT pin system-provided packages here (tensorrt, Jetson.GPIO, PyGObject,
# ...): --system-site-packages already exposes them, and pinning would try to
# fetch them from PyPI.
#
# Bootstrap (from bebop-vision/), also done by
# `scripts/install-jetson.sh --setup-voice`:
#   1. python3 -m venv --system-site-packages .venv
#   2. .venv/bin/pip install --upgrade pip
#   3. .venv/bin/pip install --extra-index-url https://download.pytorch.org/whl/cu132 \
#        'torch==2.13.0+cu132' 'torchvision==0.28.0+cu132'
#   4. .venv/bin/pip install -e .
#   5. .venv/bin/pip install -r requirements.txt
