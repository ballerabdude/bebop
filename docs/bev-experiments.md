# BEV student overnight experiments — 2026-10-19

Follow-up: [SegFormer-B5 and resolution experiments](bev-segformer.md).

This is the lab notebook for the first improvement pass after the model-only
live BEV.  Everything below is measured on `navd_session_20261018_193932`
(the held-out drive).  The robot was off; no engine was built or deployed.

## TL;DR

The biggest problem was not the architecture.  It was the teacher hazard
label.  The original labels marked a person holding a tray as a 663-cell
hazard blob; re-running the same rule with the current SAM checkpoint and
geometry gave 5 cells.  A full re-label (`labels_base2`, 2,100 frames) plus
the existing DINOv3 ViT-S/16 student and a hazard Tversky loss produced a
large held-out improvement:

| Metric (held-out drive) | old model | base2 model | delta |
|---|---:|---:|---:|
| mIoU | 0.518 | **0.545** | +0.027 |
| floor IoU | 0.811 | **0.835** | +0.024 |
| wall IoU | 0.662 | 0.629 | -0.033 |
| obstacle IoU | 0.535 | 0.522 | -0.013 |
| hazard IoU (raw) | 0.064 | **0.194** | +0.130 |
| hazard precision (raw) | 0.084 | **0.439** | +0.355 |
| hazard recall (raw) | 0.212 | **0.258** | +0.046 |
| hazard F1 (raw) | 0.121 | **0.325** | +0.204 |
| coverage precision | 0.812 | **0.816** | +0.004 |
| coverage recall | 0.920 | 0.912 | -0.008 |

The **live** service masks semantic cells by the predicted coverage head.
That mask makes the old hazard results much worse; the new model is still a
large improvement:

| Hazard, live coverage mask | old | base2 model |
|---|---:|---:|
| precision | 0.062 | **0.389** |
| recall | 0.145 | **0.194** |
| F1 | 0.087 | **0.259** |
| IoU | 0.046 | **0.149** |

With a hazard-probability threshold of 0.15 instead of argmax, the masked
numbers become precision 0.276 / recall 0.291 / F1 0.283 / IoU 0.165.
That is a recall/safety choice; argmax is the conservative default.

`wall` and `obstacle` lost a little.  The new model is not a free win on
those classes, but the floor, mIoU and hazard behavior are materially better.

## What the teacher labels looked like

The original labels are preserved under `labels/`; the regenerated set is
`labels_base2/` (same frame stamps, same rule, current SAM + current rig
geometry).

- `navd_session_20261018_193932`, stamp `1792366793952299585`: original
  **663 hazard cells** (9% of the BEV) around a person carrying a tray;
  base2 **5 cells**.  The person is an obstacle, not a hole.
- `navd_session_20261018_193224` (playroom): base2 keeps **117,546 hazard
  cells**.  This drive is a real ~34 cm step down into the playroom; the
  lower floor is a no-go region.  Removing that supervision would be wrong.
- Full dataset hazard cells: **229,545 -> 219,392 (-4.4%)**.  Per drive:
  191614 -7,484, 191941 -130, 192050 +2,413, 193224 -647,
  193619 -3,728, 193932 (val) -577.
- The val labels were regenerated too.  This is not an untouched test set;
  it is a cleaner held-out drive after the label audit.  Future drives must
  be kept out of label tuning.

Remaining hazard noise is real: dark rugs, thresholds, shadows and people
can still produce below-plane floor points.  The long-term fix is more
actual stair/drop drives and a stricter hazard rule, not more epochs.

## Experiment ledger

`raw` is argmax over all labelled cells.  `live` is the same semantic
grid masked by the predicted coverage, matching `bev_student_runtime`.
All old-model numbers below are recomputed on `labels_base2` for a fair
comparison.

| Run | What changed | mIoU | hazard F1 (raw) | hazard F1 (live) | coverage P/R |
|---|---|---:|---:|---:|---:|
| `dino-vits16-full` | old baseline | 0.518 | 0.121 | 0.087 | 0.812 / 0.920 |
| `exp-orig-noflip` | no horizontal flip | 0.503 | 0.151 | — | 0.829 / 0.891 |
| `exp-orig-5c-unknown` | 5-class unknown | 0.319 | 0.100 | — | 0.777 / 0.855 |
| `exp-orig-4c-covsem` | coverage target = semantic, no flip, cutout | 0.502 | 0.158 | — | 0.816 / 0.798 |
| `exp-orig-flip-tversky` | precision Tversky, old labels | 0.499 | 0.151 | — | 0.817 / 0.890 |
| `exp-fixed-flip-control` | mixed labels, no hazard loss | 0.516 | 0.140 | 0.076 | 0.829 / 0.900 |
| `exp-fixed-flip-tvbal` | mixed labels, Tversky 0.5/0.5 | 0.521 | 0.155 | 0.058 | 0.838 / 0.903 |
| **`exp-base2-flip-tvbal`** | **full clean labels, Tversky 0.5/0.5** | **0.545** | **0.325** | **0.259** | **0.816 / 0.912** |
| `exp-base2-flip-tvbal-s1` | same recipe, seed 1 | 0.524 | 0.234 | — | 0.814 / 0.908 |

Negative results worth keeping:

- **5-class unknown** (class 4 for IGNORE) collapsed known-class accuracy:
  mIoU 0.319, wall IoU 0.227.  The unknown class is 68% of cells and
  dominates the CE.  Coverage masking is better than an explicit unknown
  class with this loss.
- **No flip** was not better (mIoU 0.503 vs 0.518).  The current flip is
  calibration-inconsistent (the fixed LUT is not mirrored), but it still
  acts as useful regularization; don't remove it without replacing it.
- **Coverage target = semantic** did not improve coverage precision
  (0.816 / 0.798 vs old 0.812 / 0.920).  More work is needed if far/unknown
  hallucinations are to be removed entirely.
- **Model soup** of old + new weights improved floor/mIoU slightly but
  diluted the new hazard head; the best soup's live hazard F1 was 0.076,
  versus 0.259 for the clean base2 model alone.  Keep the clean model.
- **Hazard precision Tversky** (0.7/0.3) gave very high precision but
  recall ~0.08-0.10; it is suitable only if the operator prefers almost no
  orange over stair recall.

## Commands

Re-label (one SAM pass, variants; `--variants base2` is what produced the
best run):

```bash
cd bebop-vision
.venv/bin/python tools/bev_relabel_variants.py --variants base2 --resume
```

Train:

```bash
.venv/bin/python train_bev_student.py \
  --run runs/bev-student/exp-base2-flip-tvbal \
  --labels-subdir labels_base2 --epochs 40 --stage1-epochs 5 \
  --batch-size 8 --flip-prob 0.5 \
  --hazard-weight 3.0 \
  --hazard-tversky-weight 0.5 \
  --hazard-tversky-alpha 0.5 --hazard-tversky-beta 0.5 \
  --score balanced
```

Evaluate and sweep hazard thresholds:

```bash
.venv/bin/python tools/bev_eval_run.py \
  --run runs/bev-student/exp-base2-flip-tvbal \
  --labels-subdir labels_base2
.venv/bin/python tools/bev_eval_diagnostics.py \
  --run runs/bev-student/exp-base2-flip-tvbal \
  --labels-subdir labels_base2 --out runs/bev-student/exp-base2-flip-tvbal/eval
.venv/bin/python tools/bev_hazard_sweep.py \
  --run runs/bev-student/exp-base2-flip-tvbal \
  --labels-subdir labels_base2 \
  --out runs/bev-student/exp-base2-flip-tvbal/eval/hazard_sweep.json
```

## Recommended next steps

1. **Collect stair/drop drives.**  The current set has one real step-down
   playroom and otherwise mostly rugs/shadows/person false positives.  A
   hazard head cannot learn what is not in the labels.  Capture ascending
   and descending stairs at multiple distances and lighting.
2. **Review base2 hazard labels**, not just metrics.  A stricter rule
   (stairs prompt only, or local drop + prompt) should be tested on those
   new drives before another full training run.
3. **Build/deploy the new engine** only after operator review; compare the
   live orange area and stair behavior.  A hazard threshold (0.15) is a
   configurable recall/safety trade; argmax is the conservative default.
4. **Recover wall/obstacle**: add wall/obstacle dice or focal terms, or
   train a second clean-label run without the hazard Tversky and compare
   the wall/obstacle trade.  The new model lost 3.3 wall IoU and 1.3
   obstacle IoU relative to the old model.
5. **If far/unknown hallucinations persist**, revisit an explicit
   semantic-valid/unknown head with a correctly balanced loss (unknown
   weight 0.1-0.2 or a separate binary head), not the 5-class CE used here.

## Caveat

Six drives, 2,100 labelled frames, one held-out drive.  The validation
drive is correlated with the training rooms and was relabeled during this
pass.  Treat these numbers as a development signal, not a final benchmark.
The clean-label recipe also has seed variance: the same 40 epochs with
seed 1 produced mIoU 0.524 / hazard F1 0.234 (raw), versus 0.545 / 0.325
for seed 0.  Both are above the old 0.518 / 0.121, and the direction of the
label fix is consistent, but the headline number is a best-of-two seed.
